# Olmeda-EW200-Final-Project---The-Elden-Throne-
## This game is called The Elden Throne and you are a lone traveller who has travelled through the world called The Shire and made your way to the Elden Throne having to Usurp the King and defeat Gideon.
![My game](mygame.png)  
### Instructions on how to play 
1. Install 'pygame'
2. Run my code 
3. Press space key to start
4. Use WASD to move around 
5. Use your mouse to throw spears towards the boss
6. Try to kill the boss before he kills you
7. Dodge his hammers
8. If you are low on health collect the health potions that randomly spawn
9. If you die, retry
10. If you win, you take the Elden Throne
